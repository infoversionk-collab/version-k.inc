■ GitHub Pagesへの公開
1. ZIPを解凍し、ファイル・imagesフォルダをGitHubリポジトリの最上位(root)へアップロード
2. GitHubの Settings → Pages
3. Deploy from a branch / main / /(root) を選択してSave
4. 表示されたURLで確認

■ 公開前に必ず確認・差し替え
1. contact.html 内の YOUR_EMAIL@example.com を正式な問い合わせメールに変更
2. company.html の法人名・所在地・代表者名・連絡先等を正式情報に更新
3. 外部画像（Unsplash）の使用可否を確認し、自社画像に差し替える
4. 各サービスの提供主体（自社提供／提携先紹介）を明確に記載
5. 採用条件、許認可、法令上必要な表示を確認
6. メールリンクはメールアプリを起動する方式です。Webフォーム送信機能は未実装です。

■ 補足
静的HTML/CSS/JavaScriptのサイトです。ログイン、会員管理、CMS、決済、フォーム送信サーバーは含みません。
